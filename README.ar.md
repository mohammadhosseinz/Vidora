# Vidora

<img src="assets/brand/vidora-logo.png" width="144" alt="شعار Vidora">

الصق رابط الفيديو، اختر الجودة واحفظه على جهازك. يدعم Vidora العربية والفارسية والإنجليزية والصينية.

[English](README.md) · [فارسی](README.fa.md) · [中文](README.zh.md)

## الاستخدام

1. الصق الرابط واضغط على فحص الرابط.
2. اختر الجودة وصيغة الملف ومجلد الحفظ.
3. ابدأ التنزيل. يمكنك إضافة فيديوهات إلى قائمة الانتظار أو إلغاء التنزيل وإعادة المحاولة.

يعرض التطبيق عنوان الفيديو وصورته والجودات المتاحة، وحجم التنزيل عندما يوفره الموقع. يجمع مساري الصوت والفيديو في ملف واحد. تتوفر صيغة WebM للجودات المتوافقة معها.

تبقى الفيديوهات على جهازك، ولا تحتاج إلى حساب Vidora. يتصل التطبيق بموقع الفيديو للفحص والتنزيل. يمكنك اختيار ملف cookies.txt محلي إذا احتاج الموقع إلى جلسة تسجيل الدخول. بعض الفيديوهات الخاصة أو المقيدة جغرافياً أو المحمية بـ DRM لا يمكن تنزيلها. ملفات تعريف الارتباط لا تضمن عمل كل رابط.

## التثبيت

الإصدار **0.1.10**. تُحفظ الحزم المحلية في `dist/`:

- **macOS مع Apple Silicon:** افتح DMG واسحب Vidora إلى Applications.
- **Linux x64:** ثبّت DEB على Ubuntu أو Debian، أو فك ضغط النسخة المحمولة.
- **Windows x64:** انقل حزمة البناء إلى Windows لإنشاء مثبّت EXE ونسخة ZIP. تتضمن الحزمة المصدر وأدوات التنزيل.

تتضمن حزمة التطبيق الكاملة أدوات التنزيل. عند استنساخ المستودع، يجب تجهيزها أولاً لأنها لا تُحفظ في Git. راجع [دليل البناء](docs/BUILD.md) و[نتائج الاختبارات](docs/VALIDATION.md). إصدار Android غير متاح بعد.
