فيدورا تطبيق مجاني لتنزيل الفيديو محلياً، مبني باستخدام Flutter وyt-dlp وFFmpeg وDeno. يدعم الإنجليزية والفارسية والعربية والصينية، مع اتجاه من اليمين إلى اليسار للفارسية والعربية. **اللغة الافتراضية هي الإنجليزية** ويمكن تغييرها من قائمة اللغة.

## حولنا
**مؤلف التطبيق: ذوالفقاری — Zolfaghari.** هدفنا جعل تنزيل الفيديو على جهازك بسيطاً مع احترام خصوصيتك.

**ادعمونا!** يساعد دعمكم على استمرار تطوير فيدورا وإصلاح الأخطاء وإصدار التحديثات. الدعم اختياري تماماً وتبقى جميع الميزات مجانية. افتح «حول فيدورا» أو زر القلب للاطلاع على خيارات الدعم.

## الميزات
- لصق رابط وفحصه تلقائياً وعرض العنوان والصورة والجودات المتاحة.
- اختيار الجودة والصيغة ومجلد الحفظ؛ عرض الحجم المعروف أو التقديري شاملاً الصوت المنفصل.
- قائمة تنزيلات مع التقدم والسرعة والإلغاء وإعادة المحاولة وفتح المجلد.
- اتصال مباشر أو إعدادات وكيل النظام أو وكيل HTTP/SOCKS مخصص.
- اختيار اختياري لملف Netscape cookies.txt خاص بالموقع، مع حذف النسخ المؤقتة بعد العملية.
- تنزيل ودمج الصوت والفيديو على جهاز المستخدم بواسطة FFmpeg.

لا يوجد خادم خلفي أو تخزين سحابي أو حساب للتطبيق. يتصل التطبيق بمواقع الفيديو والصور الأصلية. لا تُرسل الروابط أو ملفات الكوكي أو الفيديو إلى صفحة الدعم.

## التشغيل والبناء
الإصدار الحالي **0.1.7**. تم بناء نسخة Windows x64 واختبارها محلياً. تتوفر ملفات macOS وLinux وسكربتات الحزم، لكن البناء الأصلي لهذين النظامين لم يُختبر على جهاز Windows الحالي. Android غير منفذ بعد؛ واجهة DownloadEngine تتيح إضافة محرك مناسب لاحقاً.

يتطلب التطوير Flutter وأدوات البناء للنظام. البيئة المختبرة Flutter 3.41.2 / Dart 3.11. لا يحتاج مستخدم الحزمة الكاملة إلى تثبيت Python أو FFmpeg أو Deno يدوياً.

```powershell
flutter pub get
$env:LOCAL_VIDEO_TOOLS = (Resolve-Path runtime/windows).Path
flutter run -d windows
```

```sh
flutter analyze
flutter test
```

راجع [دليل البناء والحزم](docs/BUILD.md). ملفات المحركات التنفيذية موجودة في النسخة المحلية للمطور، لكنها مستثناة من Git؛ يلزم تجهيزها عند استنساخ المستودع. الحزم المحلية موجودة في dist ولا تدخل Git. [المساهمة](CONTRIBUTING.md) و[الأمان](SECURITY.md).

## الدعم
| العملة | الشبكة | عنوان الاستلام العام |
| --- | --- | --- |
| USDT | BSC / BEP20 فقط | `0x9a350193884756c2ff75e58847d8eff5441c27bf` |
| TRX | TRON — TRX فقط | `TBiSUJuPZfLAJ9VHiQuGpNVPzsEYixgp13` |

لكل بطاقة في التطبيق زر نسخ مستقل. لا ترسل USDT إلى عنوان TRX ولا تستخدم Ethereum/TRON لعنوان USDT على BSC. هذه عناوين إيداع قدمها صاحب المشروع؛ لم يتحقق المطور من الملكية أو استلام تحويل فعلي. تحقق من الحد الأدنى وصلاحية العنوان وتوفر الإيداع لدى المنصة. التطبيق لا ينشئ معاملات ولا يربط محفظة ولا يتحقق من الدفع. إعدادات الدعم العامة في assets/support.json. [تفاصيل الدعم](docs/SUPPORT.md).

## القيود والخصوصية
دعم المواقع بأفضل جهد وليس ضماناً لجميع المواقع. DRM وتسجيل الدخول ومكافحة الروبوتات والقيود الجغرافية وتغير المواقع قد تمنع التنزيل؛ الكوكي لا يضمن النجاح. قائمة التنزيلات لا تبقى بعد إعادة التشغيل. تغيير حاوية الملف لا يحول الترميز؛ جرّب MKV عند عدم التوافق. انقطاع الطاقة أو الإغلاق القسري قد يترك ملفات مؤقتة. مثبت Windows غير موقع بـ Authenticode. لا تشارك ملفات الكوكي أو أسرار الحساب في البلاغات.
