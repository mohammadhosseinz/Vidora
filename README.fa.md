# ویدورا

ویدورا یک دانلودر محلی و رایگان با رابط فارسی، عربی، انگلیسی و چینی است. بررسی لینک، دانلود، ترکیب صدا و تصویر و ذخیرهٔ فایل روی دستگاه انجام می‌شوند. برنامه حساب کاربری، بک‌اند یا فضای ابری ندارد.

## امکانات
چسباندن لینک و بررسی خودکار، تصویر و عنوان ویدیو، انتخاب کیفیت و فرمت، نمایش حجم دقیق یا تخمینی با احتساب صدا، انتخاب پوشه، صف دانلود، پیشرفت و سرعت، لغو و تلاش دوباره، باز کردن پوشه و تنظیم روش اتصال. امکان انتخاب اختیاری فایل کوکی Netscape برای همان سایت وجود دارد؛ فایل اصلی تغییر نمی‌کند و نسخه‌های موقت پس از عملیات پاک می‌شوند.

## اجرا و ساخت
نسخهٔ فعلی 0.1.6 است. Windows x64 ساخته و آزمایش شده است؛ macOS و Linux باید روی میزبان همان سیستم ساخته و آزمایش شوند. Android هنوز پیاده‌سازی نشده است.

```powershell
flutter pub get
$env:LOCAL_VIDEO_TOOLS = (Resolve-Path runtime/windows).Path
flutter run -d windows
```

راهنمای کامل: [ساخت و بسته‌بندی](docs/BUILD.md). ابزارهای آمادهٔ ویندوز در نسخهٔ محلی این پوشه موجودند ولی باینری‌ها وارد Git نمی‌شوند؛ کلون تازه باید موتورها را آماده کند. نصب‌کنندهٔ کامل به نصب دستی Python، FFmpeg یا Deno توسط کاربر نیاز ندارد. در ویندوز محیط توسعه باید امکان ساخت symlink داشته باشد.

## حمایت
دکمهٔ قلب برنامه دو کارت مستقل دارد:
- USDT فقط روی BSC / BEP20: `0x9a350193884756c2ff75e58847d8eff5441c27bf`
- TRX فقط روی TRON: `TBiSUJuPZfLAJ9VHiQuGpNVPzsEYixgp13`

هر کارت دکمهٔ کپی آدرس خودش را دارد. تتر روی Ethereum یا TRON به آدرس کارت USDT نفرستید؛ آدرس TRX هم برای دریافت USDT نیست. اطلاعات عمومی از صاحب پروژه و تصاویر صفحهٔ واریز دریافت شده‌اند؛ مالکیت یا واریز واقعی تأیید نشده است. لینک دونیت اختیاری را بعداً در `assets/support.json` تنظیم کنید. جزئیات: [راهنمای حمایت](docs/SUPPORT.md).

## محدودیت‌ها
پشتیبانی از سایت‌ها بهترین تلاش است و به معنی کارکرد با همهٔ سایت‌ها نیست. ضدربات، DRM، ورود، محدودیت جغرافیایی یا تغییر سایت ممکن است مانع شوند. کوکی رفع خطا را تضمین نمی‌کند. صف با خروج از برنامه حفظ نمی‌شود. تغییر ظرف خروجی کدک را تبدیل نمی‌کند؛ برای کیفیت‌های ناسازگار MP4/WebM، MKV را امتحان کنید. بستهٔ ویندوز هنوز امضای Authenticode ندارد. قطع برق یا force-kill ممکن است فایل موقت باقی بگذارد.

## مجوز
مجوز MIT موجود برای کد خود ویدورا حفظ شده است. وابستگی‌ها مجوزهای مستقل دارند. پیش از انتشار عمومی نصب‌کنندهٔ دارای FFmpeg GPLv3 باید منبع متناظر کامل آن و کتابخانه‌های لینک‌شده فراهم شود. [اعلام مجوزهای وابستگی](THIRD_PARTY_NOTICES.md).
